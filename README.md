# SpireX Foundation Website

A modern, responsive, and user-friendly website developed for **SpireX Foundation**. The website provides information about the foundation, internship opportunities, programs, projects, career guidance, and contact information.

## 📌 Project Overview

The SpireX Foundation website is designed to provide students and learners with a simple platform to explore learning opportunities, internships, programs, projects, and career roadmaps.

The website focuses on:

* Clean and professional UI
* Responsive design
* Easy navigation
* Interactive sections
* Career roadmap generation
* Contact form validation
* FAQ functionality
* Mobile-friendly experience

## ✨ Features

### 🏠 Home Section

* Introduction to SpireX Foundation
* Call-to-action buttons

* Foundation highlights

### ℹ️ About Section

* Foundation information

### 💼 Internship Section

## 💻 How to Run Locally

1. Clone the repository.

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder.

```bash
cd SpireX-Foundation
```

3. Open `index.html` in a web browser.

Alternatively, you can use **VS Code Live Server** to run the website locally.
